# Python Assignments — Solutions

Structure: 1 assignment = 1 folder. Inside each folder, one file per question: q1.py, q2.py, ...

## Folders
- 01_Conditional_Assignments_No_Loops — 50 files (q1-q50, q41-q50 use match-case, no loops)
- 02_For_While_Loop_Assignments — 49 files (q1-q49)
- 03_List_Assignments_List_Methods — 40 files (q1-q40)
- 04_String_Assignments_40 — 40 files (q1-q40)
- 05_String_Mini_Projects — 2 files (q1 Text Analyzer, q2 Password Strength Checker)
- 06_Conditional_Statements_Mini_Projects — 10 files (q1-q10, no loops, rules as per assignment)
- 07_Loops_Mini_Project_Assignments — 10 files (q1-q10)

Total: 201 Python files. All files passed python3 -m py_compile.

## Notes / assumed rules
Some conditional questions did not state exact rates/thresholds, so sensible standard rules were used and noted in a comment at the top of those files, e.g.:
- Grade: >=80 A, 60-79 B, 40-59 C, <40 Fail
- Ticket: <5 free, 5-12 Rs.100, 13-59 Rs.200, 60+ Rs.150
- Electricity (01/q23): first 100 units @ Rs.5, next 100 @ Rs.7, above 200 @ Rs.10
- Login (01/q27): username admin / password admin123
- ATM (01/q50): starting balance Rs.10000
For the Conditional Mini Projects (folder 06) and Loops Mini Projects (folder 07), the exact rates and rules given in the original assignment PDFs were used.

## How to run
python3 q1.py   (from inside the assignment folder)
Most programs take user input as per the question.
